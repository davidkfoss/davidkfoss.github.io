# David's Computer — Portfolio

A fully interactive fake early-2000s personal computer used as a portfolio.

🖥️ Open here:
https://davidfoss.github.io/

## Included

- Windows XP-style logon screen
- Desktop shortcuts
- Start menu
- Taskbar with open-window buttons
- Draggable / minimizable / maximizable windows
- My Documents / Explorer
- Work folder
- Research archive with ICONIP 2026 paper placeholder
- Notepad profile
- Stack.ini
- Fake Internet Explorer personal homepage
- Functional `cmd.exe` mini terminal
- Winamp easter egg
- MSN Messenger-style sign-in toast
- Minesweeper
- Recycle Bin with abandoned-project jokes

## cmd.exe commands

Open Command Prompt and type:

- `HELP`
- `ABOUT`
- `WORK`
- `RESEARCH`
- `STACK`
- `DIR`
- `CLS`
- `EXIT`
